# NCB Project Documentation

คู่มืออ่านภาพรวมโครงการ เชื่อมโยงข้อมูลจาก EOD และ EOM ไปสู่รายงาน NCB พร้อมพจนานุกรมฟิลด์ กฎธุรกิจ และรายการที่ต้องยืนยันก่อนพัฒนา

เว็บนี้สรุปจากเอกสารโครงการ 11 ไฟล์ที่ได้รับในวันที่ 18 ตุลาคม 2569 สำหรับทีมวิเคราะห์ระบบ พัฒนา ทดสอบ และผู้รับผิดชอบข้อมูล โดยแยกข้อความจากต้นฉบับออกจากข้อเสนอแนะและประเด็นที่ยังไม่สอดคล้องกัน

## หมวดเอกสาร

- [ภาพรวมและขอบเขต](/overview): Consumer, Commercial และการรายงาน LG by ID
- [Flowchart กระบวนการข้อมูล](/data-flow): ขั้นตอนสร้างรายงานและการเลือก Mapping
- [พจนานุกรมฟิลด์](/fields): Mapping เต็มตารางจากเอกสารทั้งสามแนวทาง
- [Flowchart กฎคำนวณ](/business-rules): เงื่อนไข DFD, DPD, TDR และ Amount Past Due
- [กรณีทดสอบและ UAT](/testing): ขอบเขตทดสอบและสถานะตามไฟล์ที่ได้รับ
- [ประเด็นที่ต้องยืนยัน](/open-questions): ข้อขัดแย้งและคำถามก่อนพัฒนา

## วิธีใช้เอกสาร

เริ่มจาก [ภาพรวม](/overview) และ [กระบวนการข้อมูล](/data-flow) ก่อนเลือก Mapping ที่จะใช้จริง จากนั้นอ่าน [กฎธุรกิจ](/business-rules) คู่กับ [สถานะบัญชี](/account-status) และตรวจ [ประเด็นที่ต้องยืนยัน](/open-questions) ก่อนกำหนดผลทดสอบที่คาดหวัง

ตารางฟิลด์รักษาชื่อสะกดตามต้นฉบับเพื่อให้ตามกลับได้ การปรากฏชื่อฟิลด์ในตารางยังไม่ยืนยันว่ามีฟิลด์นั้นในฐานข้อมูลจริง เอกสารชุดนี้ไม่มี DDL, stored procedure หรือซอร์สโค้ดระบบให้ตรวจเทียบ

## สถานะของข้อมูลในเว็บ

ข้อมูลนี้เป็นสรุปข้อกำหนดในไฟล์ที่ได้รับ ไม่ใช่ผลตรวจระบบ production และไม่ได้ตรวจยืนยันประกาศภายนอกฉบับปัจจุบัน คำว่า “ปัจจุบัน” ในเอกสารต้นทางอ้างถึงช่วงเวลาที่เอกสารนั้นจัดทำ โปรดดู [ทะเบียนแหล่งอ้างอิง](/sources) และวันตัดข้อมูลของแต่ละแหล่ง

**แหล่งอ้างอิง:** S01–S11 ตามทะเบียนเอกสาร
