# พจนานุกรมฟิลด์

ตารางในหมวดนี้ถอดจากตาราง Word โดยรักษาชื่อฟิลด์ ชื่อตาราง และค่าตั้งต้นตามต้นฉบับ ช่องที่ไม่มีข้อมูลแสดงเป็น “ไม่ระบุ” เพื่อแยกจากข้อความ “ค่าว่าง”, `NULL` หรือ `0` ที่เอกสารกำหนดไว้จริง

## ความหมายของฟิลด์หลัก

| ฟิลด์ | ความหมาย |
| --- | --- |
| period | เดือนและปีของงวดรายงาน เช่น 2026-05 |
| eff_date / as_of_date | วันที่มีผลและข้อมูล ณ วันที่ ต้องแยกรูปแบบภายในกับรูปแบบนำส่ง |
| customer_code | เลข CIF |
| card_id | เลขระบุตัวตนบุคคลหรือเลขทะเบียนนิติบุคคล |
| account_number | เลขบัญชีหรือเลข LG (หนังสือค้ำประกัน) |
| ownership_indicator | บทบาทผู้กู้หลัก 01 / ผู้กู้ร่วม 04 ตาม Mapping |
| credit_limit | วงเงินหรือภาระค้ำประกัน |
| amount_owned | ยอดหนี้คงเหลือ |
| amount_past_due | ยอดหนี้ที่เกินกำหนดชำระ |
| default_date | วันเริ่มผิดนัดชำระ DFD |
| number_of_days_past | รหัส DPD ที่แปลงจากจำนวนวัน |
| number_of_days_past_2 | จำนวนวันค้างชำระจริง |
| account_status | สถานะบัญชีที่คำนวณจากกฎธุรกิจ |
| date_of_restructuring | วันปรับโครงสร้างหนี้ |
| code_of_restructuring | รหัส TDR 00 หรือ 02 ตามเงื่อนไข |

## ค่าตั้งต้นและ Master

เอกสารระบุ Account Type เป็น `38`, Branch Code เป็น `0400`, Country ของ Consumer เป็น `TH` และ Member Name เป็น `TCG` โดย Member Code ต้องแยกตาม SIT/UAT/PROD ค่าในเอกสารเป็นตัวอย่างการตั้งค่า ไม่ควรนำไปยืนยันค่าของทุก environment

วันที่ไม่รายงานหลายกรณีใช้ `1900-01-01` ในข้อมูลภายใน และคู่มือแสดง `19000101` ในไฟล์นำส่ง การใช้ sentinel date ต้องแยกจาก SQL NULL และค่าว่างอย่างชัดเจน

## เอกสารรวมฟิลด์และฝ่ายงาน

S10 เปรียบเทียบฟิลด์ Consumer กับ Commercial พร้อมชื่อบน report ความหมาย ระบบ Magic/DCS ฝ่ายงาน และคอลัมน์ Confirm จึงใช้ตามผู้รับผิดชอบข้อมูลได้ แต่ค่า Confirm ในไฟล์ไม่เพียงพอจะสรุปว่าข้อกำหนดได้รับอนุมัติแล้ว

**แหล่งอ้างอิง:** S02, S05, S07, S10 และ S11 ดู [ทะเบียนเอกสาร](/sources)
