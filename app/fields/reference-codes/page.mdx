# รหัสอ้างอิงและประเภทนิติบุคคล

บสย. ต้องแปลงประเภทเอกสารของผู้กู้ให้ตรงกับข้อมูลที่เตรียมส่ง NCB (เครดิตบูโร) เริ่มจากรหัสระบุตัวตนบุคคล แล้วจึงดูประเภทนิติบุคคลที่อ้างอิงใน Mapping EOM

ถอดจาก S05 ตาราง Mapping ID Type และ NCBRegistrationMaster รักษาข้อมูลตามต้นฉบับเพื่อใช้เทียบ schema จริง

## ID Type

| ID Type | ความหมาย |
| --- | --- |
| 00 | Unspecified (ไม่ระบุ) |
| 01 | Citizen ID (เลขประจำตัวประชาชน) |
| 02 | Civil Servant ID (เลขบัตรข้าราชการ) |
| 03 | Enterprise (เลขบัตรรัฐวิสาหกิจ) |
| 04 | Trade No. (เลขทะเบียนการค้า) |
| 05 | Alien (เลขบัตรต่างด้าว) |
| 06 | Thai Passport (เลขที    หนังสือเดินทางไทย) |
| 07 | Foreign Passport/ID (เลขประจำตัว/หนังสือเดินทางชาวต่างชาติ) |
| 09 | Other (อื่นๆ) |
